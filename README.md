# ExpenseFlow — Expense Tracker Website

A responsive HTML/CSS/JavaScript website adapted from the Tkinter expense tracker concept.

## Features
- Add and delete expense records
- Month-based overview, budget tracking, category donut visualization
- Search transactions and export CSV
- Local browser storage (no server or account required)
- Responsive design, pastel purple/mint palette, motion effects

## Publish with GitHub Pages
1. Create a GitHub repository (for example `expense-tracker`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then Save.
6. Wait for the Pages URL to appear.

Note: records are saved in the browser's localStorage on the device/browser used. They do not sync between devices.
